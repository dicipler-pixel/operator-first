# Operator First

Formal and reproducible materials for the Operator-First research programme.

The repository includes Lean/mathlib proofs, exact computational certificates, negative controls, and status ledgers. Research branches may contain scoped work that is not yet merged to `main`; theorem claims are tied to green CI and explicit status files.

For the current Collatz finite-prefix programme, see the `collatz-barrier-lean` formal spine and its extension PRs. The formalized results concern exact finite affine identities, power-gap survival barriers, exact binary phase layers, and finite certificates. They do **not** constitute a proof of the Collatz conjecture.
