# Probe reconstruction or an invisible perturbation

Stable ID: `OBS-PROBE-SPAN`

## Statement

A target linear observable on real symmetric matrices is uniformly determined by probe readings iff its matrix lies in the span of their probe outer products.

## Assumptions

Fixed real symmetric matrix class and linear quadratic-form readings; special PSD boundary data require separate treatment.

## Failure mode

A finite candidate-list identification does not prove identifiability over the full matrix class. Complex response requires imaginary cross probes.
