# Compound Eye — All Eyes Observatory 1.0

Open **All_Eyes_Observatory.html** and select a problem. All compatible display
views begin enabled. Play advances through freshly computed frames. Pause,
scrub, switch eyes, or choose a two-readout trajectory to see disagreements.
Read each panel's coordinate and source: acquired settings and prime prefixes
are not elapsed laboratory time.

For actual live recomputation, from the included instrument folder run:

```sh
python -m pip install -r requirements.txt
python projects/all_eyes/serve.py
```

Open the local address it prints. Enable **Recompute with live Python**, then
enter a value or move the slider. This executes the registered scientific eyes
at that parameter. It does not interpolate the saved curves. The service is
local to your computer and does not connect to a laboratory or instrument feed.
The offline HTML remains usable without Python for all recorded trajectories.

## Reproduce

```sh
python projects/all_eyes/coverage.py
python projects/all_eyes/sweeps.py
python projects/all_eyes/verify_findings.py
python projects/all_eyes/build_viewer.py
node projects/all_eyes/test_ui.js
```

The last command tests actual interface handlers in a DOM/canvas harness. It
does not claim a fresh browser screenshot. With the server running, set
OBSERVATORY_TEST_URL to its local URL to additionally exercise live HTTP output.

Scientific requests, inputs, result hashes and adapter descriptions are retained
in results. Compressed JSON is lossless. A case's source kind distinguishes
mathematical, processed and synthetic inputs. Eye toggles control display, not
evidence selection; the exported frame keeps every computed result.

## Runtime repair

Runtime 1.0.1 resolves the original adapters' source root inside the preserved
modular release. Earlier focused suites missed this broken source-folder lookup.
The repair leaves every registered eye, implementation and set unchanged. The
original sixteen quantum eyes now execute from the current registry, share one
kernel call, and match in serial and parallel execution.

Use a common parameter to compare readouts, then test the relation with a
controlled change or independent identity. Overlay normalization is a display
operation; shared kernels, repeated projections and related formulas are not
independent confirming experiments. A visual pattern is not a proof of a
physical mechanism.
