### Code recovered in 5.2

5.1 held 37 late eyes (15 Earth–Moon side scanner, 22 Yang–Mills cross-theorem) by name and
contract only. Their code was found on the branches that produced them and is now attached to
each record as `implementation_recovered` (files in `implementations/`, hashes in
`implementations/INDEX.json`). Registered contracts are unchanged.

## Files

- `ALL_EYES_CATALOG.json` — all 589 records.
- `EYE_SOURCE_LEDGER.json` — for every eye, every build it was found in.
- `implementations/` — code for the added eyes and the 37 recovered ones.
- `scripts/` — the extractor and the build, so the union can be re-run when new eyes appear.
