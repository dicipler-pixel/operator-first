## Reproduce the integrated release

Python 3.12 and Node.js 20 or newer are needed for complete verification. Install the pinned Python dependencies with `python -m pip install -r requirements.txt`. Run `python run_all.py`. This executes QHE, peeling, UPG, Diophantine and horizon suites, then mixer algebra and UI-harness checks. Histories and implementation hashes are validated. It does not replay every historical experiment, refit raw QHE shots, or compile Lean.

Rebuild the offline page with `python build_portal.py`. Individual entry points remain `run_qhe.py`, `run_upg.py`, `run_diophantine.py`, `run_horizon.py`, and `projects/peeling_cascade/run_cascade.py`. Model contracts differ: choose relevant eyes and supply each one's required inputs.
