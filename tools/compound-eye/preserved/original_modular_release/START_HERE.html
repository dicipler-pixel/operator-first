Run the full project

Python 3.11 or later. From the extracted project folder:

python -m pip install -r requirements.txt
python run_project.py
python tests/test_machine.py

No GitHub account or hosted service is needed. Browser pages work without installing Python.

A boundary you can move

Keep the additive charge fixed. Change the coupling to an outgoing channel and watch its response. This small calculator evaluates the same analytic formula used in the supplied continuum model.

Model-energy units · Inside the channel band

Band [0,4], hopping 1. Inside the band:
Γ(E) = v² √[4 − (E − 2)²]

The parent level is coupled to a semi-infinite lead. Γ is a self-energy response scale; a resonance pole width requires its own analysis.
