B95L4 → L5 theorem

The threshold profile reads the cycle type.

C(ε)  =  ∑j #{ k : sin²(πk/Lj) ≥ ε }
flat in ε if and only if every cycle is a transposition — at fixed Hamming cost

Each moved point of a permutation defect carries one unit displacement, and that is a direction; two directions stay apart at threshold ε when sin²θ ≥ ε. The Gram matrix of the family splits over the cycles, so the number of resolvable directions is fixed by the cycle type and by nothing else — half the demand at every threshold when the cycles are transpositions, running with ε as soon as they are longer.
