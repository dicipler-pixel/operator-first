## Step 2 — boundary at cap W+1: BLOCKED, and not by budget

| W | \|K_W\| | boundary edges | distinct exits | return_1 | return_2 | return_3 | ADVANCE |

**#ADVANCE = 0, necessarily.** The `ac-r2-v1` move set is closed under inversion:

    INV = {0,1, 3,2, 5,4, 7,6, 9,8, 11,10, 13,12}

so the capped move graph is **undirected**. Every boundary edge `s -> s'` with
`s` in `K_W` has its reverse `s' -> s` available under cap `W+1`, because
`|s| <= W <= W+1`. So every exit state is one move from `K_W` and is classified
RETURN. This holds for every row and every cap; it is a property of the move
set, not of this instance. Measured: every distinct exit state returned at
depth 1, none at depth 2 or 3, none left over.

Steps 3-5 therefore never execute. No NEGATIVE is recorded for this row: a
kill-condition NEGATIVE would assert that a search was run and failed, and no
search was run. The protocol needs a repaired RETURN/ADVANCE definition first.


## Addendum — the repaired definition is also empty

The literal RETURN test is vacuous by move-set symmetry (above). The obvious
repair is to forbid the single backtrack edge and re-ask the question. That was
implemented in `acc_port.c` and measured at W=20:

| row | \|K_20\| | distinct exits | exits with >=2 edges back | exits with exactly 1 | ADVANCE (repaired) |
|---|---|---|---|---|---|
| ac-02923 | 242,824 | 289,404 | 41,312 | 248,092 | **0** |
| ac-02576 | 370,224 | 529,316 | 89,788 | 439,528 | **0** |

So even with the trivial backtrack removed, every exit state still reconnects to
`K_W` within three moves by some other route. The wall is not porous at radius 3.
About 14% of exits have two or more independent edges back; the remaining 86%
have exactly one, and still return by a longer route inside the radius.

This is a measurement about the boundary, not a budget failure. Making the port
search meaningful needs a larger escape radius or a different criterion than
3-move reconnection; that is a protocol decision, not something to pick here.


## Addendum 2 — escape-radius sweep: the port never opens

Ran 2026-09-22 on request, after the radius-3 result. `acc_radius.c` computes,
for each exit state with exactly one edge back into `K_W` (the only ones that
can ever be ADVANCE), the **minimum number of moves back into `K_W` with that
one edge forbidden**. That histogram gives ADVANCE at every radius at once:
`ADVANCE(R) = #{exits with min_return_dist > R}`.

| row | W | exits with exactly 1 edge back | sampled | min_return_dist |
|---|---|---|---|---|
| ac-02923 | 20 | 248,092 | 2,000 | **all d = 2** |
| ac-02576 | 20 | 439,528 | 2,000 | **all d = 2** |
| ac-00472 | 20 | 811,072 | 2,000 | **all d = 2** |
| ac-02217 | 20 | 592,176 | 2,000 | **all d = 2** |
| ac-02923 | 22 | 1,607,052 | 800 | **all d = 2** |

8,800 sampled exit states across four rows and two caps. Every one returns at
distance exactly 2. None at 3, none beyond, none unresolved. So
`ADVANCE(R) = 0` for every `R >= 2`, and raising the radius cannot help.

### Why distance 2, and not further

Boundary exits by entering move class:

| row | from moves 0-1 (invert) | from 2-5 (multiply) | from 6-13 (conjugate) |
|---|---|---|---|
| ac-02923 | 0 | 7,461 | 281,943 |
| ac-00472 | 0 | 25,249 | 900,623 |

No exit is ever created by moves 0 or 1: those preserve total length, so they
cannot carry a state of length `<= W` to one of length `W+1`.

For the ~97% created by a conjugation move the 2-move return is **provable**.
Let `s` in `K_W`, and `s' = m(s)` with `m` a conjugation acting on relator `i`.
Let `n` be the move inverting the *other* relator `j != i`. Then `n` preserves
length, so `n(s')` is legal at cap `W+1`; `m` and `n` touch disjoint relators,
so they commute; and `n(s)` is in `K_W` because `K_W` is move-closed and `n`
preserves length. Hence

    s' --n--> n(s') = m(n(s)) --INV[m]--> n(s)  in K_W

is a 2-move return, and its first move is not the forbidden edge because
`n(s')` still has length `W+1` and so is not in `K_W`.

For the ~3% created by a multiplication move (2-5) that commuting argument does
not apply, and no proof is offered here; those were simply observed at `d = 2`
in the sampling along with the rest.

### Consequence

Reconnection radius is not a usable discriminator on this graph at any setting.
The wall is not a membrane with pores; it is locally two-way everywhere. A port
search keyed on reconnection distance cannot be rescued by tuning, and needs a
different criterion entirely — a directional one, not a topological one.

`acc_boundary.c` (boundary + classification):

```c
static Side K, E;

static int in_K(const St*s){ return side_find(&K,s)!=0xFFFFFFFFu; }

int main(int argc,char**argv){
    if(argc<6){ printf("usage: W kbudget ebudget l0 a.. l1 b..\n"); return 2; }
    int W=atoi(argv[1]);
    uint64_t kb=strtoull(argv[2],0,10), eb=strtoull(argv[3],0,10);
    int ai=4;
    int l0=atoi(argv[ai++]); uint8_t a[MAXW]; for(int i=0;i<l0;i++) a[i]=(uint8_t)atoi(argv[ai++]);
    int l1=atoi(argv[ai++]); uint8_t b[MAXW]; for(int i=0;i<l1;i++) b[i]=(uint8_t)atoi(argv[ai++]);

    if(!side_init_n(&K,kb)){ printf("ALLOC_FAIL_K\n"); return 1; }
    if(!side_init_n(&E,eb)){ printf("ALLOC_FAIL_E\n"); return 1; }

    // ---- close K_W ----
    CAP=W;
    St s0; memset(&s0,0,sizeof s0);
    packw(a,l0,&s0.a0,&s0.b0); s0.l0=l0;
    packw(b,l1,&s0.a1,&s0.b1); s0.l1=l1;
    int isnew;
    side_intern(&K,&s0,0xFFFFFFFFu,255,&isnew); K.lvlend=K.nst;
    while(K.lvlend>K.head && K.nst+64<kb){
        uint32_t stop=K.lvlend;
        while(K.head<stop && K.nst+64<kb){
            uint32_t si=K.head++; St cur=K.pool[si],r;
            for(int m=0;m<14;m++){ if(!apply(&cur,m,&r)) continue;
                side_intern(&K,&r,si,(uint8_t)m,&isnew); }
        }
        K.depth++; K.lvlend=K.nst;
    }
    int kclosed = (K.lvlend<=K.head);
    printf("K_W W=%d %s states=%u\n", W, kclosed?"CLOSED":"BUDGET", K.nst);
    fflush(stdout);
    if(!kclosed){ printf("ABORT_K_NOT_CLOSED\n"); return 3; }

    // ---- enumerate exit states at cap W+1 ----
    CAP=W+1;
    uint64_t edges=0;
    for(uint32_t i=0;i<K.nst;i++){
        St cur=K.pool[i],r;
        for(int m=0;m<14;m++){
            if(!apply(&cur,m,&r)) continue;
            if(in_K(&r)) continue;
            edges++;
            side_intern(&E,&r,i,(uint8_t)m,&isnew);
        }
    }
    printf("BOUNDARY edges=%llu distinct_exits=%u\n",(unsigned long long)edges,E.nst);
    fflush(stdout);

    // ---- how fast does an exit state get back into K_W ? ----
    uint64_t r1=0,r2=0,r3=0,adv=0;
    for(uint32_t i=0;i<E.nst;i++){
        St s=E.pool[i],x,y,z; int back=0;
        for(int m=0;m<14 && !back;m++){
            if(!apply(&s,m,&x)) continue;
            if(in_K(&x)){ back=1; r1++; }
        }
        if(back) continue;
        for(int m=0;m<14 && !back;m++){
            if(!apply(&s,m,&x)) continue;
            for(int n=0;n<14 && !back;n++){
                if(!apply(&x,n,&y)) continue;
                if(in_K(&y)){ back=1; r2++; }
            }
        }
        if(back) continue;
        for(int m=0;m<14 && !back;m++){
            if(!apply(&s,m,&x)) continue;
            for(int n=0;n<14 && !back;n++){
                if(!apply(&x,n,&y)) continue;
                for(int o=0;o<14 && !back;o++){
                    if(!apply(&y,o,&z)) continue;
                    if(in_K(&z)){ back=1; r3++; }
                }
            }
        }
        if(!back) adv++;
    }
    printf("CLASSIFY return_1=%llu return_2=%llu return_3=%llu ADVANCE=%llu\n",
           (unsigned long long)r1,(unsigned long long)r2,(unsigned long long)r3,
           (unsigned long long)adv);
    return 0;
}
```
