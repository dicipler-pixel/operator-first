# Compound Eye HARNESS v2 — search-screening design

## Non-negotiable rule

A compressed signature is never exact state equality. Cheap eyes route attention.
Only exact replay, exact component closure, exact target meet, or an explicitly
scoped mathematical obstruction may certify/prune.

## Retention ladder

1. **Exact identity** — freely reduced ordered relator pair.
2. **Cheap scalar census** — lengths, imbalance, exponent ledger.
3. **Labelled local response** — keep all 14 official move labels separately.
4. **Structural state record** — cyclic support and local child geometry.
5. **Deep nonabelian record** — Magnus degree 2/3, mod-p signatures.
6. **Ordered path record** — ordered transport, move n-grams, gross/net currents.
7. **Exact search memory** — DAG node, component membership, verified suffix/certificate.

When two candidates collide at a level, descend one level deeper. Do not pay for a
deeper eye on a population already separated by a cheaper eye unless the run protocol
explicitly calls for full retrospective observation.

## Large-area screening

### Census pass — every expanded state
Compute exact state hash, length/imbalance, exponent ledger, cyclic structure and
the labelled 14-move response. Search engines already generate those children, so
the response should be harvested from the same proposals rather than recomputed.

### Collision pass — only unresolved cells
If the cheap signature merges states whose future behavior differs, evaluate
Magnus-2, Magnus-3/mod-p, history or other specialist eyes on that cell.

### Frontier pass
Contract a completed interior component to entry/exit ports. Retain internal path
costs. Run labelled boundary-channel eyes on crossing states. Histogram counts are
kept, but never substitute for the ordered move-label vector.

### Path pass
For promising paths keep ordered move history. Track:
- future-move profile persistence/turn;
- useful-move-set Jaccard;
- path-ordered GL(2,Z) transport;
- gross versus net shear;
- conjugation currents;
- ledger-fiber holonomy events;
- multi-scale trace windows.

### Exact-memory pass
Probe exact reverse balls, Highway/suffix dictionaries and verified corridor mouths.
Representation changes are useful only when compiled back to official primitive moves.

## Cross-project ideas incorporated

- **Compound Eye / DAG:** exact shared states may reuse work only when context and
  remaining choices are genuinely the same.
- **Light Keeps the Ledger:** scalar counts can lose orientation; fixed labelled
  probes distinguish equal coarse spectra. Boundary filtering is the right place to
  spend expensive response measurements.
- **Formal Bridges / complete-complex holonomy:** ordered composition can retain
  information discarded by scalar norms; closed coarse transport may have nontrivial
  fiber displacement.
- **Directional Transport / projector persistence:** measure whether the *space of
  useful moves* persists or rotates between steps.
- **Collatz barrier work:** preserve ordered correction data; totals alone can erase
  the mechanism. Separate final endpoint behavior from all-prefix survival.
- **Peeling Cascades:** elimination leaves memory; one-step silence is not global
  silence. Escalate to deeper response moments only when one-step probes collide.
- **Kakeya / Earth–Moon:** exact obstruction certificates are reusable; passing a
  necessary eye is inconclusive; coverage claims stay bounded to the enumerated region.
- **Yang–Mills retained/hidden operator stack:** cheap retained data and expensive
  hidden-sector response are separate layers; do not pretend one replaces the other.
- **ACC Highway / corridors:** exact suffix reuse and component contraction beat
  rediscovering known interiors.
- **Atlas:** residuals and mechanism classes matter; duplicate eye names do not make
  independent evidence.

`ac-02842`:

  **1 RETURN / 6 SAME / 7 UP**;

This is the model for large-scale screening: do not deepen until the cheaper view
actually collides.
