### 2.1 Class-level cross-row splice (`class_splice*.py`, `splice_bob.py`) — COMPLETE on the rows listed
- **Idea:**
  - Two states are the same class when each relator is the same up to cyclic rotation and inversion, and the pair is compared as a set.
  - Index every state on every held road (1,746 verified paths + every ledger `path.best` + session 1 `roads_latest.txt` = 5,682 roads, 7,051 to 7,530 classes when indexing only the last 32 to 34 moves).
  - Walk our road. Wherever a state shares a class with a state on ANOTHER row's road, glue our prefix to that row's tail.
  - Compile the joined class sequence into real moves with the road-keeping DP.
- **DP (`skel_dp_fixed.py`):** Dijkstra inside each class using inner moves (0, 1, 6–13), with multiplications (2–5) to step to the next class.
  - Tight setting: GROW 1, SLACK 3, MAXC 8. Loose: GROW 2, SLACK 4, MAXC 16. Wider: GROW 2, SLACK 6, MAXC 24.
  - Session 2's fix: a move that shortens a relator is always allowed.
- **Speed:** indexing 5,682 roads took over 20 min in plain Python until I cached `canon()` per word (one relator is unchanged by every move). After that it took about 1 min. One DP join takes 1 to 60 s.
- **Produced:**
  - 9 distinct new-lineage roads on Bob's rows (equal to our best, or 1–2 over).
  - The ac-05598 40 road whose (y,x) finish became the **sac-05598 41 tie** (accepted).

### 2.2 Orientation-aware splice (`splice_orient.py`, in sweeps/git) — COMPLETE on 02288 / 04493 / 06969 / 00145 / 02528 / 08078 / 08578
- **Bug found:** almost every class-splice join returned None, because the donor held OUR relators in the OTHER slots. AC moves cannot swap slots.
- **Fix 1:** on a swapped join, relabel the donor tail with `SW = {0:1, 1:0, 2:4, 3:5, 4:2, 5:3, 6:10, 7:11, 8:12, 9:13, 10:6, 11:7, 12:8, 13:9}`. The DP then ends at (y,x). That route + `[15,15]` is a Stable line.
- **Fix 2 (orientation price):** a per-slot BFS (that slot's conjugations and inversion only, word cap 24, depth 9) from our state to the donor state. Keep a join only if position + donor remainder + price ≤ target + 2.
  - At ac-02288, position 29, the price was 4 + 3 = 7 moves, which was the whole saving.
  - The price pruned 676 joins before the DP.
- **Fix 3:** build the tail's class road from the DONOR state, not ours.
- **Usage:** `python3 splice_orient.py ac-XXXXX` (needs `skel_dp_fixed.py` and the donor files; env EST_SLACK / OR_SLACK).
- **Produced:** every join now lands (134/134 on 02288, 303/303 on 06969, 461 on 00145). These are new-lineage AC and (y,x) roads. Best result = the held length. No score.

## 7. Tips and traps

1. **Slot swap.** A class match (frozenset) does not mean the slots line up. Check `canon(a[0]) == canon(b[0])`. If it doesn't hold, relabel the donor moves and aim at (y,x). This explained about 100% of my failed joins.
2. **Orientation is not free.** A class match near the end typically costs 3–7 orientation moves. Price it before the DP.
3. **Queue the held check, not just the record check.** I pushed 6 + 14 redundant lines (ac-04493 52, sac-00145 42) that the team already held. Compare against our accepted history on both boards.
4. **My local `stable_core.verify` copy was NOT calibrated.** It rejected known accepted Stable lines. For Stable, replay the route on the AC core to (y,x) or (x,y), then let `plan_offline.py` / the official CLI do the Stable check.
5. **`-march=native` binaries** die with SIGILL after a container move. Build with `-O2` only.
6. **Plain-Python class indexing** is quadratic per word. Cache `canon()` per word (lru_cache); each move leaves one relator unchanged.
7. **Killing jobs.** `pkill -f name` from a bash call whose own command line contains `name` kills that shell. Kill by PID.
8. **Background jobs die when the container restarts** (it happened 4 times). Anything long needs a checkpoint, or the owner's PC.
9. **The DP returns None at the tight setting** when orientation needs more than MAXC 8 extra moves. That is a scope limit, not a miss. Try (2,4,16) and (2,6,24) before calling a join dead.

## 8. Exact results (with scope)

- **E1.** Inner moves (0, 1, 6–13) never change which slot a relator is in. A (y,x) end can only come from the multiplications. So a DP or search that keeps a class road ending in the class of (x,y) can reach (y,x) only if the last multiplication set it up. **Scope:** an exact statement about the move set.
- **E2.** The relabel map SW (section 2.2) conjugates the AC move set by the slot swap: applying SW(m) to (r1, r0) gives the swap of m applied to (r0, r1). So a donor road from state b to (x,y) becomes, relabelled, a road from swap(b) to (y,x).
