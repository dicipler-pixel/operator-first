THE PROBLEM (SAIR Andrews-Curtis Challenge, AC track, move spec ac-r2-v1)
- A state is two freely reduced words (r0, r1) over x, y. Integers: x=1, x^-1=-1, y=2, y^-1=-2.
- 14 moves (each followed by free reduction, NOT cyclic reduction):
  0: r0 <- r0^-1   1: r1 <- r1^-1   2: r0 <- r0 r1   3: r0 <- r0 r1^-1   4: r1 <- r1 r0   5: r1 <- r1 r0^-1
  6..9: r0 <- g r0 g^-1 for g = x, x^-1, y, y^-1      10..13: r1 <- g r1 g^-1 for g = x, x^-1, y, y^-1
- Goal: reach exactly (r0, r1) = ([1], [2]) i.e. (x, y). Score = number of moves. Shorter is better.
- Stable AC track (sac-ids, spec sac-r8-v1) has its own move numbering (stabilise/destabilise moves). The simple rule
  we use: an AC road + [16,15] is accepted as a Stable road 2 longer; an AC-move road ending at (y, x) + [15,15] too.
- Points: beat the record = 1.0; tie a record held by k teams = 2^-k. A tie also halves the holder's points on that row.
- Official checker (the only judge): git clone https://github.com/SAIRcompetition/Andrews-Curtis, checkout
  a0fd6e6f52d82c93ccc06ab91d81e8fa3678256e, then from the repo root:
  PYTHONPATH=competition/tools python3 -m verifier --manifest competition/tools/verifier/data/manifest.json --submission YOURFILE.txt
  Submission lines look like:  ac-00018: [3,13,8,...]   (one per line). Only lines it accepts count.
