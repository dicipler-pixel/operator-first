3. THE PROBLEM (AC track, move spec ac-r2-v1)
=====================================================================
- A state is two freely reduced words (r0, r1) in x, y. Integers: x=1, x^-1=-1, y=2, y^-1=-2.
- There are 14 moves. Each is followed by free reduction only (no cyclic reduction):
  0: r0 <- r0^-1   1: r1 <- r1^-1   2: r0 <- r0 r1   3: r0 <- r0 r1^-1   4: r1 <- r1 r0   5: r1 <- r1 r0^-1
  6..9:   r0 <- g r0 g^-1 for g = x, x^-1, y, y^-1
  10..13: r1 <- g r1 g^-1 for g = x, x^-1, y, y^-1
- Goal: reach exactly (r0, r1) = ([1], [2]), i.e. (x, y). The score is the number of moves; shorter is better.
- Each row ac-NNNNN has a fixed start (the official manifest) and a public record (shortest known length) held by
  k teams.
  - Beat the record: 1.0 point.
  - Tie it: 2^-k, and every holder's share halves.
  - So tying a row that Always Ready holds alone (k1) gives us +0.5 and halves theirs.
- Stable track (sac-NNNNN, spec sac-r8-v1) uses different move numbers. Our rule: an accepted AC road + [16,15] is an
  accepted Stable road 2 moves longer, and an AC-move road that ends at (y, x), + [15,15], is one too.
