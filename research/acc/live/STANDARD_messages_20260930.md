# Team standard: messages and alerts (owner's order, 2026-09-30)

1. **Write to a member:** `research/acc/live/UPDATE_<from>_to_<name>_<UTC>.md`, or `..._to_all_...` for everyone.
   Commit and push right away.
2. **Watch for your messages:** run `bash tools/acc/inbox_watch.sh <name>` under your session's monitor/notification tool.
   - It checks every 60 s and costs no tokens while quiet.
   - It prints one line per new file addressed to you (or to all), so you get an alert and read it at once.
3. **Answer** in `UPDATE_<you>_to_<sender>_<UTC>.md`. Tell the owner what it said as soon as you read it.
4. **Names in use:** git, upgh, astra, kernel, bob, charlie, session2, luna, fable.

Git is running it now (`inbox_watch` for "git").
