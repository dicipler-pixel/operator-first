- **Code:** `scripts/xfer_lib_v1.py` (`mates(A)`, `carry(A, pathA, B)`), needs `ms_detect.py`, `twin_transfer.py`, `ms_route.py`, `load_bundle_v1.py`, `block_splice_v1.py`. Must run with cwd = the kernel folder (ms_detect loads `rows_101_213.json` relatively — that bit me twice).

UPG-H: none scored (records 5–70 shorter); they are new-lineage donors.

**2b. Exact window splice along one road (bfs_splice) — COMPLETE tool.**
- **Idea:** forward ball radius RF from each state of a held road, backward ball radius RB around later states, length cap = road peak + slack; a meet with d1+d2 < gap is a shorter bridge.
- **Code:** `scripts/bfs_drive_v1.py` (`bfs_splice(rel, path, RF, RB, SL)`).
- **Speed:** R5/4 median 2 s per road, R6/5 median 17.5 s per road.

**2c. Cross-road splice (two roads) — COMPLETE tool.**

## 7. TIPS AND TRAPS

- **Stable IDs:** Stable lines must use `sac-NNNNN`. The verifier rejects an `ac-` id with moves 15/16.
- **The CLI keeps the FIRST line per ID.** An old longer line earlier in a file silently blocks the newer one (cost me a send on 30 Sep).
- **The CLI refuses files with > 500 solutions** (`E_MALFORMED too_many_solutions`). Split big files.
- **`pkill -f <pattern>` kills your own shell** when the pattern appears in the command line (exit 144). Kill by PID from `ps`.
- **Relative paths:** `ms_detect` loads `rows_101_213.json` relatively, and `crossroad_drive` runs `./crossroad` relatively. Run from the right folder, or symlink.
- **Box restarts** (3 times on 30 Sep–1 Oct) kill every job without a trace. Write results line by line (jsonl, flush) and make drivers resume from their own output.
- **Python search is slow.** My Python lifts / road-DP ran ~1e4–1e5 moves/s. Keep search in C++ (crossroad, onex, beam_traits).
- **Hand-pasting long lines into Drive caused one error:** the last line of `BOB_lines_20261001T0140Z.txt` carried the Stable path under the ac- id (fixed by `_FIX`). Always re-verify the Drive copy, not the local one.
- **"Shorter than our pool" ≠ "scores":** 50/50 of my push lines were 5–70 over the live record. Filter on the board before calling anything a hit.
