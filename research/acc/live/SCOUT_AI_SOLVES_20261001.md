## 4. Methods worth stealing for shortest-path search on presentations

1. **Exact BFS balls as a distance oracle plus bidirectional splicing and waypoint restarts.** nahomar built exact state balls up to total length 16/17 (129M-514M states) in C++, then cost-bucketed macro beam search, cross-path splicing and waypoint restarts, with bidirectional shortcuts. Treat each solved instance's path as a library of waypoints for other instances. Source: https://github.com/nahomar/andrews-curtis-solver (MIT). Same source reports a useful negative: learned value functions collapsed to length proxies, so do not expect a cheap learned heuristic to beat total length.
2. **Plan for detours (two-hump / detour width), not monotone length descent.** Lean-proved: detour width and graph distance are independent (https://github.com/ph4ge/ac-detour-width); the RL literature names the same obstacle (https://arxiv.org/pdf/2606.21611, title only read). Practical consequence: beams with a hard length cap discard the intermediate-length states a shortest path may need; allow staged length budgets and run capped exhaustive search to know which box is already exhausted. alejandrozarco exhausted caps 29-32 from two length-14 frontier presentations without reaching AK(3) or the trivial presentation (https://github.com/alejandrozarco/andrews-curtis-ms14), which is a map of dead regions.
3. **Greedy plus path-concatenation: solve easy relatives first and reuse their paths.** The RL case study (Shehper et al.) found greedy search succeeds on much of the family and that hard instances dominate difficulty (https://arxiv.org/pdf/2408.15332; I relied on the title and a snippet, not a fresh read). The NeurIPS follow-up reports 753 trivializations by adding LLM-discovered theorems (reusable sub-paths) to RL (https://neurips.cc/virtual/2025/131071, snippet). Reusing verified sub-paths as macro-moves is the common thread.
4. **Closed-form parametric paths for algebraic subfamilies.** Robby955 gives explicit constructions for G(p,s) divisibility cases, a 2-multiplication-minimal period path for s >= 1, and a Lean-checked residual certificate (https://github.com/Robby955/ac-square-divisibility, code Apache 2.0, paper CC BY 4.0). If any pool instances match these shapes, these give provably short paths with no search. Needs a relator-shape match against the 10,115 pool.
5. **Seed paths from automated equational reasoning, then shorten.** Lisitsa converts Prover9 proofs into AC sequences (https://arxiv.org/abs/2501.18601 and the Miller-Schupp papers at https://www.sciencedirect.com/science/article/pii/S2666657X2500028X). These tend to be long but valid starting paths for hard Miller-Schupp cases; length-reduction (shortcutting, splice, local rewrite) on them is a natural pipeline. Check each paper's data availability and licensing before use.
6. **GPU beam search with learned diffusion-distance heuristics from the Cayley-graph literature.** CayleyPy RL (https://arxiv.org/html/2502.18663v3), cayleypy-cube (https://github.com/khoruzhii/cayleypy-cube) and GFlowNet shortest-path work (https://arxiv.org/pdf/2603.01786) show beam search guided by learned distance estimates on huge implicit graphs, including a one-line beam-search tweak the abstract calls the "X-trick". Caveat: these are finite permutation groups; the AC graph is infinite and nahomar's value-function collapse suggests the learned-heuristic route needs care. Snippet-level only; not fetched.
