# 11. Paper I: “electron as minimal spectral loop”

This was historically important for the program even though the theorem does not survive.

The proposed identifications were:

- `SF=\pm1`: minimal charge; 
-  Spin`^c` twisting: spin `1/2`; 
-  reversed spectral orientation: antiparticle; 
-  protected flow: stability. 

### What was valuable

It forced us to ask the right question:

> What is the smallest nontrivial persistent spectral structure?

That question survives completely.

### What did not survive

We did not derive an electron.

The flat `T^2` model itself actually gives the stronger reason why: its full spectrum is paired and its naive net SF cancels.

Today's better question is:

```math
\boxed{
\text{What is the minimal persistent projector/subspace transport class?}
}
```

That is much closer to the later program.

---

# 12. Paper II: renormalized spectral-flow invariant

Paper II tried to define

```math
n(x)=SF(\gamma_{x_0x})
```

independent of path.

This led us toward:

-  path groupoids, 
-  cocycles, 
-  cohomology, 
-  gluing. 

### Useful insight

Spectral flow is naturally additive under concatenation:

```math
SF(\gamma_2\circ\gamma_1)
=
SF(\gamma_2)+SF(\gamma_1).
```

That genuinely suggests a `\mathbb Z`-valued cocycle/functor on an appropriate path or Fredholm-operator category.

### Old error

We claimed that any two paths between endpoints differ by a loop with zero SF.

That is not automatic.

Nontrivial loops of self-adjoint Fredholm operators can themselves carry nonzero spectral flow.

So path-independence requires an additional quotient/restriction; it cannot simply be asserted.

---

# 13. Spectral Cohomology Layer

That failure led us to one of the better old ideas:

> treat spectral flow as a cocycle on a path/groupoid structure rather than force it to be a scalar function of endpoints.

That is mathematically much healthier.

The lasting version is:

```math
SF:\mathrm{Mor}(\mathcal G)\rightarrow\mathbb Z,
```

with

```math
SF(g\circ f)=SF(g)+SF(f).
```

This is one of the old constructions I would definitely retain.

# 14. Paper III: ordered spectral flow

We then tried to define

```math
C_1\prec C_2
```

whenever a positive-flow path connected them.

This was the beginning of the **time/order** program.

### Valuable insight

Spectral transport can carry orientation without introducing physical clock time.

### Major old overclaim

We repeatedly said reverse traversal was “topologically obstructed.”

But for a path `\gamma`,

```math
SF(\gamma^{-1})=-SF(\gamma).
```

The inverse path generally exists mathematically.

So **spectral flow by itself does not produce irreversibility**.

To obtain a genuine partial order, we need an admissibility relation that excludes some reverse morphisms for an independent reason.

This is one of the biggest lessons from the old work.

This eventually connected beautifully to the quantum metric.

That old intuition is worth keeping.

# 16. Paper IV: spectral stress

Several versions existed.

The most important form became

```math
\Sigma_{ij}
=
\sum_k w_k
(\partial_i\lambda_k)
(\partial_j\lambda_k).
```

For a tangent vector `v`,

```math
\Sigma(v,v)
=
\sum_k w_k
(d\lambda_k(v))^2.
```

### What this actually is

This is a Gram/pullback quadratic form generated by the spectral map

```math
\Lambda:x\mapsto
(\lambda_1(x),\ldots,\lambda_N(x)).
```

With weights `W`,

```math
\boxed{
\Sigma=d\Lambda^{T}W\,d\Lambda.
}
```

That is mathematically meaningful.

It is:

-  symmetric, 
-  positive semidefinite for `w_k>0`, 
-  sensitive to eigenvalue response, 
-  generally degenerate. 

### Important modern interpretation

Its null space is

```math
\ker\Sigma
=
\{v:d\lambda_k(v)=0\;\forall k\}.
```

These are **isospectral directions**.

That was an early glimpse of the later idea that eigenvalues alone are insufficient: an eigenvalue-null direction can still rotate eigenspaces dramatically.

That is precisely why the projector/QGT geometry is stronger.

# 17. The modern replacement for old `\Sigma`

This is one place where later work clearly improves the old formulation.

Rather than using only eigenvalues,

```math
d\Lambda,
```

we now naturally look at a spectral projector

```math
\Pi
```

and its tangent

```math
d\Pi.
```

The intrinsic Grassmannian/QGT metric has the form

```math
g(V,W)
=
\frac12\operatorname{Tr}(VW)
```

for projector tangents `V,W`, with associated symplectic form

```math
\Omega(V,W)
=
-i\operatorname{Tr}\bigl(\Pi[V,W]\bigr).
```

This retains **eigenspace/subspace motion even when eigenvalues barely move**.

That is a direct maturation of the old “spectral stress” idea.

# 18. Weak-overlap/inverse-square idea

The old argument was:

```math
\lambda\sim\frac1r,
```

therefore

```math
\nabla\lambda\sim\frac1{r^2},
```

therefore

```math
\Sigma\sim\frac1{r^4}.
```

Then we variously claimed derivatives/integrals produced Newtonian behavior.

This was not closed.

There were also inconsistent versions:

```math
F\sim r^{-3},
\qquad
V\sim r^{-2},
```

which are **not Newtonian**:

```math
V_{\rm Newton}\sim-\frac1r,
\qquad
F_{\rm Newton}\sim-\frac1{r^2}.
```

So none of the old inverse-square claims should be treated as proved.

# 19. Mostow rigidity

We hoped hyperbolic knot complements might close the scale argument.

Mostow–Prasad rigidity says a finite-volume hyperbolic manifold of dimension at least three has its hyperbolic geometry determined by its fundamental group up to isometry.

That is powerful.

But it creates a problem for our old scaling argument:

if the hyperbolic structure is fixed, then the volume is fixed.

So setting

```math
L\sim\operatorname{Vol}^{1/3}
```

does not give us a freely varying large-distance parameter within a fixed knot complement.

Thus

```math
\text{Mostow rigidity}
\not\Rightarrow
1/r^2.
```

This bridge stays open.

---

# 20. Exponential-decay simulations

An old simulation claim was

```math
e^{-r/\lambda}
\approx
\frac1{r^2}
```

at large distances.

That is mathematically false asymptotically.

Exponential decay and algebraic decay are fundamentally different:

```math
e^{-r/\lambda}
=o(r^{-N})
```

for every fixed `N`.

An exponential can resemble a power law over a finite plotting window, but that is not an asymptotic derivation.

This entire old argument should be archived as a **failed test that taught us what not to use**.

# 24. Paper V: open / closed / neutral taxonomy

We tried to classify stable objects into:

-  open flows, 
- `w=+1` closed loops, 
- `w=-1` closed loops, 
- `w=0` neutral pairs. 

### Key mathematical correction

From

```math
\pi_1(T^2)=\mathbb Z\oplus\mathbb Z
```

one does **not** obtain

```math
w\in\{-1,0,+1\}.
```

General loops have winding pair

```math
(p,q)\in\mathbb Z^2.
```

The trichotomy was therefore a **chosen restricted sector**, not an exhaustive theorem.

This is important to preserve in the archive because it shows exactly where physical intuition compressed the actual topology too early.

# 30. The “echo” involution

Calling it **echo** was actually useful because it prevented a physical theorem from being smuggled into an abstract categorical involution.

# 34. Lorentz reconstruction

We once claimed a two-state complex module forced

```math
SL(2,\mathbb C)
```

and hence Lorentz symmetry.

That is not true.

A two-dimensional complex representation space alone has a much larger `GL(2,\mathbb C)` freedom; one needs determinant, bilinear-form, Hermitian-form, or other preservation conditions to select subgroups.

So:

```math
\text{2 states}
\not\Rightarrow
SL(2,\mathbb C).
```

Archive the ambition; discard the theorem.

# 35. Dirac operator “emergence”

We proposed

```math
D=
\lim_{\epsilon\to0}
\frac{T^\epsilon-I}{\epsilon}
```

for a `\mathbb Z`-shift `T`.

That is not valid without embedding the discrete action into a continuous one-parameter group.

There is no intrinsic infinitesimal `\epsilon` inside `\mathbb Z`.

Again, the good question survives:

> Can the generator of an appropriate continuous representation of the transport groupoid be Dirac-type?

The old proof does not.

# 36. Gauge reconstruction

We explored internal phase freedom:

```math
v\mapsto e^{i\theta}v,
```

and local phase choices requiring a connection.

That is standard gauge geometry:

```math
A\mapsto A+d\chi.
```

### What survives

If an SMC representation is a complex line/vector bundle over parameter space, phase redundancy naturally introduces a `U(1)` connection.

### What did not survive

The category itself did not uniquely force electromagnetism.

Nor did it force `SU(2)` or `SU(3)`.

The later Yang–Mills restart is a much stronger and more concrete treatment of gauge structure than this old branch.

# 37. Tensor product / fusion

We tried to promote SMC into a tensor category with

```math
V_n\otimes V_m\simeq V_{n+m}.
```

This is a perfectly legitimate **toy graded category definition**.

But APS gluing does not automatically imply that exact fusion rule.

And there is a more basic closure issue:

gluing two torus-boundary knot exteriors along their entire torus boundaries generally produces a **closed 3-manifold**, not another torus-boundary knot exterior.

Therefore naive geometric gluing is not automatically an internal tensor product on the originally defined object class.

This is a major issue we did not appreciate early enough.
