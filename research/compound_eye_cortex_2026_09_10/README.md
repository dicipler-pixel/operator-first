# Compound Eye Cortex 0.1

This research branch asks a narrower question than "how many more eyes can we add?":

> How do we make hundreds of eyes behave like a scientific instrument rather
> than a catalog of calculations?

The synchronized baseline on `main` remains Compound Eye Universal 3.2. Cortex
0.1 is an **additive meta-layer**. It reads the same immutable eye registry and
run records; it does not overwrite existing eyes or broaden their claims.

## What is implemented now

`cortex.py` is standard-library Python and provides:

- transparent attention routing over the actual eye catalog;
- explicit research-question requirements and evidence coverage;
- shared-lineage diagnostics so dependent outputs are not counted as independent;
- change detection across repeated run records;
- exact rational blind-spot / dual forcing certificates;
- exact finite projector overlap and distance;
- exact scalar energy-resolved versus one-floor Schur penalty comparison;
- detection of equal semantic objects with different represented-state futures.

Run:

```bash
python -S research/compound_eye_cortex_2026_09_10/test_cortex.py
python -S research/compound_eye_cortex_2026_09_10/cortex.py attention "projector forcing boundary"
python -S research/compound_eye_cortex_2026_09_10/cortex.py question research/compound_eye_cortex_2026_09_10/examples/hidden_connection_question.json
```

The test suite is a meta-layer check. Passing it does not certify any scientific
claim that an eye might later analyze.

## Why this is more than more eyes

The current `machine.py` already gives us a retina and optic nerve: versioned
eyes, dependency DAG, context contracts, shared computation, result hashes and
evidence records.

The cortex adds attention, memory, blindness checks, evidence dependence,
question coverage and next-action planning.

See `ARCHITECTURE.md` for the full design and `THEOREM_SOURCE_MAP.json` for the
cross-project structures we can turn into carefully scoped meta-capabilities.

## Development rule

New meta-capabilities must remain as strict as the existing eye contracts:

- no majority-vote truth;
- no theorem transfer without an explicit source-to-target dictionary;
- no numerical diagnostic promoted to formal proof;
- no hidden execution of chatbot-generated code;
- no collapse of alternate representations when representation changes future moves;
- no loss of source/energy/support labels when the next theorem needs them.

The intended long-term endpoint is a private research companion in which natural
language produces a **reviewable question specification and action proposal**,
while registered scientific eyes, exact checkers, and formal tools remain the
acceptance mechanisms.
