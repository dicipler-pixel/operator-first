# Additional-source audit

These findings supplement the combined manuscript. Original attachments remain
unchanged in `sources/`; their SHA-256 identities are in `source_inventory.json`.

| Source | Retained result | Necessary qualification or correction |
|---|---|---|
| Gram infographic and ladder v4 | Normalized Gram data encode reflection shape; orientation is a separate record | Fix size before calling the map an O(d) bundle. The SO(d) base is the oriented cover; rank strata need separate charts. A physical rotation requires a specified connection and vertical-motion data. |
| Angle insert | Normalized rank-one commutator stress equals the squared sine of the singular-line angle | Higher rank is outside that identity. The continued-fraction tangent needs the stated limiting left direction. A line angle loses signed orientation. |
| FOFT v2.2 flow | Lax isospectrality and the exact Henrici-budget derivative | A normal matrix need not be scalar. The equilibrium corollary states the needed degenerate-spectrum condition; the abstract overstates it. The Frobenius budget is not identified with physical heat. |
| ZERO-AND-SPAN-01 | Selected ranges are invariant under positive rescaling | R pinv(R) is an orthogonal range projector, not generally the non-Hermitian Riesz projector named in its comment. The latter commutes with K; the former need not. |
| Ladder symmetrization | Positive diagonal similarity gives a real, diagonalizable interior spectrum | Strict interlacing assumes distinct poles; a degenerating boundary metric does not prove that every boundary point is exceptional. |
| Original COSMO-GRAD-01 | Reproduces the correction to an earlier proposed flow and its non-isotropic endpoint | The script is an adversarial audit, so completion must not be summarized as all original claims passing. Its printed positive derivatives refute the older descent claim. |

The new registered methods execute 340 evaluations with 745 assertions and three
intended refusals. Independent flow integration has maximum eigenvalue drift
2.63e-12. The original gradient audit's longer run has drift 8.79e-10 and final
commutator norm 2.51e-9. Both are numerical controls of the stated finite flow.
Large lattice census scans, all cosmological claims, and the entire continued-
fraction corpus were not rerun as part of this focused source intake.

The source files contribute to the combined paper's observation/reconstruction
framework. None establishes that atomic number is a projector rank, that
ionization converts Au into Pt, or that a Gram hypersurface is an electronic
Fermi surface. The physical identification remains a specified-material task.
