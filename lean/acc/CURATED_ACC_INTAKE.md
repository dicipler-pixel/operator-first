## Vetted formal material worth importing

These are theorem-level results already present on older private branches. They
are the first candidates for promotion beside ACWindow because they add reusable
logic rather than search noise.

### 1. Closed-well bottleneck theorem

Source branch: `formal/acc-complete-frontier-2026-09-13`  
Source file: `ACCWell.lean`  
Source blob: `da881ef963f16bcff35a54bb645bd553959683a5`

Main theorem:

`ACCWell.descent_forces_cap_exit`

If a checked set contains the start, is closed under every move whose target
stays below a height cap, and contains no lower state, then every finite path
ending lower must visit a state above the cap.

This is generic graph logic. It does not prove an ACC census by itself.

### 2. Complete first-exit frontier theorem

Source branch: `formal/acc-complete-frontier-2026-09-13`  
Source file: `ACCFrontier.lean`  
Source blob: `fa3fcf67d613d378d35d3e22307382c477b4a288`

Main theorem:

`ACCFrontier.cap_closed_exit_forces_above_cap_edge`

This is the corrected first-exit statement: an elementary move may jump across
more than one length shell. The theorem requires only that an actual traversed
edge exits the closed component to a target above the cap. Do not reintroduce a
false `B -> B+1` shell assumption.

  `ac-00738`, `ac-02555`, `ac-02217`, and others.

Promotion rule for a numerical row:

1. exact official start words from a pinned SAIR source;
2. exact frozen move semantics;
3. frontier exhaustion, not timeout/BUDGET/NOHIT;
4. exact target-absence check;
5. deterministic count and digest;
6. independent checker or second implementation;
7. false/corruption controls;
8. exact source commit/environment;
9. Lean theorem gate green at the exact promoted head.

## Keep out of the theorem core

The following are useful research history or search-routing information but
should not be dumped into the Lean theorem layer as if they were proofs:

- finite-quotient distance as a long-range hardness measure;
- integral exponent-sum matrix distance as a hardness measure;
- one- and two-ply branching counts;
- latent cyclic cancellation by itself;
- naive cyclic/conjugacy canonicalization as a transition-complete quotient;
- beam-search, stochastic or timeout NOHIT records;
- old leaderboard/submission bookkeeping;
- un-rechecked historical CLOSED labels;
- Magnus/nilpotent depth profiles when used only as heuristic signal;
- Compound-Eye scores without a theorem linking them to the claimed property.

Negative results remain valuable in the research ledger; they simply do not
belong in the proof kernel.
